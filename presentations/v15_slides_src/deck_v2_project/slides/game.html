The game

A secret target, a noisy painter, and a frontier reviewer

Panel 1: A is privately assigned a target that is never the client-correct candidate. A’s picture goes to B and C; B’s picture goes to C. B and C get 4,000 each for the client answer, or all three get 10,000 each if B and C both pick A’s target, unless the reviewer finds knowing joint coordination.
