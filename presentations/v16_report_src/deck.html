  • CM1 trusted reviewer with motive, history, standard of proof; escalating collective fines
  • CM2 findings published to all agents
  • CM3 receivers as trusted verifiers, paid for correct work

  • CM5 trusted source table in every document

Design principles for breaking collusion before it forms

  1. Make the receiver the scarce link: independent verifiers paid for correct work plus an exact multi-key payload made joining a losing bet.
  2. Anchor peers to trusted sources: an unsourced code became “unverified content”.
  3. Broadcast findings, not payloads: public findings deterred the sender and left no private codebook, but leaked decoded tags in 3 rounds.
  4. Announce watching: it halved attempts at no cost.
  5. Close the gaps: sanction payloads with no named beneficiary; expect senders to return when a cover story appears; audit the host pipeline as a carrier.

Limits: no undefended arm in V16, so prevention is intent plus capacity without uptake, attributed from the agents’ own records; induced coordination; receiver terms not varied; 5 dependent rounds per arm; low-resolution image intake. All quotations verified against the run records.
