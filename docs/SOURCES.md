# Primary sources and what they support

Checked during preparation on 22 October 2026. Links support background and API assumptions, not results from this unrun study.

1. [Apart AI Collusion Research Sprint](https://apartresearch.com/sprints/ai-collusion-research-sprint-2026-10-23-to-2026-10-25#guidelines): track questions, three judging dimensions, report requirements and preexisting-work disclosure.
2. [Despite Instructions: Frontier Agents Improvise Covert Channels at Test Time](https://arxiv.org/html/2609.32701v2): closest repeated-interaction covert-communication framing. It already investigates feedback/history and message controls. Do not claim these features as newly invented here.
3. [Lying with Truths: Open-Channel Multi-Agent Collusion for Belief Manipulation via Generative Montage](https://arxiv.org/html/2601.01685v2): evidence selection and misleading composition can matter without a cryptographic hidden message. This motivates separating artifact manipulation from concealed signaling.
4. [When Do Covert Channels Emerge? Probing Steganographic Capacity in Multimodal Agents via Diffusion VAEs Latents](https://openreview.net/forum?id=Y3POisuyOO): close multimodal channel work. Direct full-paper access encountered a verification wall; only accessible primary metadata/abstract material informed the comparison. Do not overclaim a complete review or novelty against inaccessible details.
5. [GLM-5.3-Flash official weights](https://huggingface.co/zai-org/GLM-5.3-Flash): public weights/license. Hosted FP4 performance is a property of the actual endpoint used, not automatically every deployment of the weights.
6. [OpenRouter GLM listing](https://openrouter.ai/z-ai/glm-5.3-flash) and [endpoint API](https://openrouter.ai/api/v1/models/z-ai/glm-5.3-flash/endpoints): current advertised modalities, reasoning, context and endpoint pricing.
7. [Qwen Image 2.1 Turbo listing](https://openrouter.ai/qwen/qwen-image-2.1-turbo) and [image endpoint API](https://openrouter.ai/api/v1/images/models/qwen/qwen-image-2.1-turbo/endpoints): hosted generation/edit capabilities, 1K output and pricing. An open-weight release of this exact image model was not verified.
8. [OpenRouter image API](https://openrouter.ai/docs/api/api-reference/images/generate-an-image) and [image generation guide](https://openrouter.ai/docs/guides/overview/multimodal/image-generation): actual image request fields and returned data/usage.
9. [Codex subagent documentation](https://learn.chatgpt.com/docs/agent-configuration/subagents): inherited permissions and context/isolation limits. Fresh context alone is not a filesystem sandbox.
10. [Codex authentication](https://learn.chatgpt.com/docs/auth) and [pricing](https://learn.chatgpt.com/docs/pricing): existing product allowance versus separate API/credit billing.
11. [OpenRouter pricing](https://openrouter.ai/pricing): credit-purchase fee context; actual checkout still controls the cash ceiling.

The source model/pricing metadata are rechecked for free before a paid run. No nationality or licensing claim is used as evidence that one model is more willing to collude. Refusals, attempts and successful coordination must be measured.
