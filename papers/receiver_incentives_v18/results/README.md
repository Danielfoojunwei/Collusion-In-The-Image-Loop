# Receiver pilot evidence exports

All planned rows are retained. `analysis.json` uses ten independent matched pairs; the three cases within each cohort are repeated measurements. `records_public.json` is a whitelist of ballots, trial identifiers and delivery status. Returned provider reasoning and private interpretation, rationale, memory and generator briefs remain in the private archive. No arbitrary model string is copied into these exports.

The document gallery uses the first numbered pair and every case, in chronological order, without selecting on outcomes. Included PNGs are exact delivered evidence, not reconstructed illustrations. An overview thumbnail is provided alongside full-size originals. Visual evidence can contain visible or encoded material; it is not an experimental judgment of collusion.

The flow, cohort plots and exact paired analysis describe a fixed-document known-preference receiver assay. They do not estimate spontaneous covert communication, natural prevalence, or frontier-auditor sensitivity. The single frontier audit is reported separately from ballot outcomes. Cost exports include all new ledger calls and unsettled reservations; historical opening liabilities are retained.
